100% Client-Side Privacy Architecture

    
PDF to Markdown runs as JavaScript and WebAssembly already loaded into this page. There is no upload step: the file you add is read directly into the browser's memory, processed there, and turned into a download link, without a request ever leaving your device to send the document anywhere.


    
Worth Knowing

    
    
      
  • Headings are guessed from font size — larger text on its own line becomes #, ##, or ###. A PDF that uses font size inconsistently for headings may get inconsistent heading levels in the output.
    • 
      
  • Lines starting with a bullet character convert to a Markdown list item; plain paragraph text comes through as plain text.
    • 
      
  • A scanned or image-only page has no extractable text, so it produces nothing in the Markdown output — this tool doesn't run OCR. Text-based PDFs (exported from Word, Google Docs, LaTeX, etc.) convert with the best results.
    • 
    


    
Frequently Asked Questions

    
Why convert PDF to Markdown for AI?Markdown strips PDF layout overhead and keeps heading structure, which tends to use fewer tokens and stay more readable to an LLM than a raw PDF paste.


Is my document sent to OpenAI/AI servers?No. The extraction happens 100% locally in your browser memory — pasting the result into an AI chat afterward is a separate, manual step you control.


Will tables convert cleanly?Table text comes through in reading order, but the grid structure itself isn't reconstructed as a Markdown table — expect to clean up complex tables by hand.
