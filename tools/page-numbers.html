100% Client-Side Privacy Architecture

Page Numbers & Watermark runs as JavaScript and WebAssembly already loaded into this page. There is no upload step: the file you add is read directly into the browser's memory, processed there, and turned into a download link, without a request ever leaving your device to send the document anywhere.

Worth Knowing
  • The starting page number and the starting position in the document are independent settings — you can begin counting at "1" while still skipping the cover page, or start numbering partway through at any number you choose.
  • Watermark opacity (10%–80%) and text size (24–72pt) are adjustable sliders; the angle is a choice between diagonal, horizontal, or reverse diagonal rather than a free-rotation control.
  • Both features write directly into the PDF's page content, so the result looks the same in every reader — it isn't a browser-only overlay.
Frequently Asked Questions
Can I exclude the cover page?Yes. Set the numbering to start from page 2 (or any page) so earlier pages are left unnumbered.
Can I customize watermark opacity and angle?Opacity and text size are fully adjustable sliders. Angle is a choice of diagonal, horizontal, or reverse diagonal.
Can I add both page numbers and a watermark at once?Not in a single pass — they're separate modes. Run the tool once for page numbers, then feed the result back in for a watermark pass (or vice versa).
