100% Client-Side Privacy Architecture

Unlock PDF runs as JavaScript and WebAssembly already loaded into this page. There is no upload step: the file you add is read directly into the browser's memory, processed there, and turned into a download link, without a request ever leaving your device to send the document anywhere.

Worth Knowing
  • This does not crack or guess passwords. If a document needs a password to open and you do not have it, this tool cannot help, and neither can any honest one — that is what encryption is for.
  • Each page is re-rendered as a high-resolution image once decrypted, so the unlocked copy is for viewing and printing rather than selecting or copying text.
  • Only use this on documents you own or have permission to modify. Removing protection from someone else's file may breach their rights or your agreement with them.
Frequently Asked Questions
It says a password is required. What now?The document is genuinely encrypted. You need the password from whoever created it — there is no way around that by design.
Will the unlocked file keep selectable text?No — pages come out as images so the visual layout is preserved exactly, but text is no longer selectable or searchable. Keep your original if you need that.
Can I unlock a file without the password?No. If opening the file itself requires a password, that password is required here too — there is no bypass.
Is decryption done locally?Yes. The password and file never leave your browser; decryption happens entirely in local memory.
